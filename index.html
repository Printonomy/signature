How to Install in Outlook / Exchange

  1. Open Outlook → File → Options → Mail → Signatures → New
  2. Name the signature (e.g. Printonomy) and click OK
  3. Click the HTML source button (or use the web-based OWA editor)
  4. Open signature.html from this repository
  5. Copy the <table>…</table> block and paste it into the editor
  6. Replace [YOUR NAME], [YOUR TITLE], [YOUR PHONE], and [YOUR EMAIL] with your details
  7. Save and assign the signature to your account
